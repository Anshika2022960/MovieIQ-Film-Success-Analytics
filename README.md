# MovieIQ – Film Success Analytics Dashboard

MovieIQ is an interactive data analytics dashboard that examines
historical movie performance using financial, audience and genre data.

## Project Features

- Data cleaning and feature engineering
- Budget and revenue analysis
- Profit and ROI analysis
- Genre-wise success analysis
- Popularity and audience-rating analysis
- Correlation heatmap
- Independent T-Test
- Chi-Square Test of Independence
- Interactive Streamlit filters
- Downloadable filtered dataset

## Success Definition

A movie is considered successful when:

Revenue > Budget

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
